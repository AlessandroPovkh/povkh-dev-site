# Navigation rules

Status: ready for human review.

## Primary navigation

Retain the current `Работы` item pointing to `/ru/work/`. Do not add a new top-level item for complex products or cases.

## Homepage proof navigation

- The paired proof section contains one KZMS card and one ENDOkey card.
- Each card's primary destination is its internal Povkh.Dev case route.
- The external result link is secondary and clearly labelled by role; it must not replace the case route.
- The section also offers a path to `/ru/work/` for the complete set of work.

## Work index

- KZMS and ENDOkey are the primary external-client evidence and appear before POVKH LAB.
- POVKH LAB remains explicitly founder-led.
- Card labels must describe the subject and performed scope, not invented outcomes.

## Case pages

- Breadcrumb model: `Главная / Работы / <Кейс>`.
- Each case links back to `/ru/work/`.
- Each case may link to its verified external result in a new context using a client-facing result label.
- A related-case cross-link between KZMS and ENDOkey is required because the pair demonstrates the same method across different complex subjects.

## Secondary, utility and footer

No change in this packet. Existing footer and utility routes remain outside scope.
