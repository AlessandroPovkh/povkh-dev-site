# DESIGN CRITIQUE

Project: Povkh.Dev homepage — high-fidelity draft 05
Brief: Preserve all existing messaging and cases while creating a memorable, technically expressive, sales-oriented studio site.
Context: Desktop and mobile homepage prototype reviewed on 2026-08-24.

## Thesis

The draft has a convincing identity at its strongest moments: the hero, the KZMS comparison, POVKH LAB, and the Giulia before/after stage. The system weakens between those moments because several sections revert to undifferentiated dark rectangles with text. The next iteration should not add decoration indiscriminately; it should make every visual device express the same argument: Povkh.Dev turns fragmented product information into a navigable path to choice.

## Formal analysis

### Composition

The hero establishes asymmetric tension between a large typographic field and a circular product image. The vertical line through the viewport currently reads as a layout guide accidentally left visible: it does not connect two related objects, indicate progress, or respond to interaction. Removing it will strengthen figure–ground separation and let the orbit become the dominant spatial device.

The problems, method, and result sections use repeated equal rectangles. Similarity groups the items correctly, but excessive similarity removes hierarchy and progression. Four different ideas become four interchangeable cards.

### Color and atmosphere

Near-black, warm white, and electric pink create a clear signature. The color system is strongest when pink identifies a state change or action: the KZMS divider, active case index, and emphasized sentence. It is weaker when large areas are only flat black. These areas need value shifts, grid texture, image fragments, or light fields—not additional accent colors.

### Typography

The large grotesk typography has sufficient authority and matches the studio's technical/editorial position. Body copy is readable. The missing layer is typographic choreography: background-scale words, annotations, cropped technical fragments, and changes in alignment can give sections rhythm without changing the actual copy.

### Interaction and rhetoric

The strongest interactions expose evidence: KZMS compares old and new; Giulia lets the viewer inspect both sites. This establishes the correct rule: interaction should reveal reasoning or proof. Purely ornamental dividing lines and empty hover effects should be removed.

## Strengths

1. The hero communicates the proposition quickly through scale, contrast, and one focused product image.
2. Every case has its own visual temperature, so the portfolio demonstrates range rather than a single template.
3. The sticky case index turns a long proof section into an understandable sequence.
4. Pink acts as a signal color rather than a general fill, preserving its force.

## Opportunities and directions

1. **Replace the hero divider with a semantic field.** Use orbit annotations—product, context, choice—and a cursor-responsive light field. The image then reads as an object being examined, not as decoration beside copy.
2. **Turn the four problem cards into a diagnostic instrument.** Give each problem a distinct visual model: terminology noise, a broken route, disconnected channels, and a launch radar. The diagrams should remain abstract enough not to compete with copy.
3. **Make the method a workbench, not a table.** Use a continuous numbered rail, layered evidence fragments, and changing spatial density to show research becoming focus, route, and verification.
4. **Make outcomes one connected system.** Replace the 2×2 grid with a continuous signal path from “Находят” to “Обращаются,” with each state occupying a different depth and visual treatment.
5. **Add atmospheric continuity.** Use restrained grain, coordinate grids, cropped project fragments, and scroll reveals so the page does not collapse into flat black between major case images.

## Comparative references

- [Fourmeta navigation on Awwwards](https://www.awwwards.com/inspiration/interactive-site-navigation-fourmeta-agency): navigation is part of the case-study experience rather than a detached menu.
- [Garden Eight portfolio overview](https://step1.dev/gallery/NPalJ1bFgDjmOJQif9QBO): scale, masked typography, and motion create atmosphere without requiring every section to become a card grid.
- [Don Bisho case study](https://monarqeg.com/case-studies/don-bisho/): custom interaction density is justified when each interaction supports the narrative.

## Recommended refinement path

1. Remove the hero divider and rebuild the right side as an annotated product-observation field.
2. Redesign problems, method, and outcomes as three different visual systems connected by the same signal/path metaphor.
3. Preserve all existing copy and evidence interactions; add motion only where it reveals state, sequence, or causality.
