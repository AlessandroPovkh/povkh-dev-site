# Povkh.Dev draft 09 — reference lock

## Brief

Designing the Povkh.Dev homepage for B2B/B2B2C buyers of complex products on web.

- Goal: move from problem recognition through project proof to a low-friction project discussion.
- Tone: dark editorial interface with technical precision and cinematic proof.
- Risk: decorative technology that obscures meaning or makes the work look like a template demo.
- Must remember: pink is a signal for focus, state and action; it is not general decoration.
- Constraints: preserve all approved text, meaning, claims and cases; prototype stays inside Harness.
- Path: direct iteration from the user-approved direction, followed by visual QA.

## Source truth

Primary source: the three user-supplied references and the approved `Dark Editorial Interface` direction.

Preserve:

- near-black canvas;
- large neutral sans typography;
- asymmetric editorial composition;
- real project media as proof;
- sharp borders, minimal radius and controlled pink signals.

Secondary research:

- Obys Experiment Space: continuous experimental environment and movement between structured fragments;
- Locomotive work/navigation: clear structured navigation, subtle kinetic transitions and media-led cases.

Reject:

- repeated generic cards;
- violet/indigo gradients;
- soft SaaS pills and rounded containers;
- fake 3D or abstract illustration;
- motion without feedback, continuity or hierarchy.

## Decision ledger

| Decision | Source | Role | Why |
|---|---|---|---|
| Full-width technical navigation grid | User references + Locomotive | Primary navigation | Makes the site feel like a controlled system while preserving clear routes |
| Full-screen menu with oversized section labels | User references | Navigation state | Adds one memorable interaction without hiding content structure |
| Pink only for active state, targets and primary action | User requirement | Semantic accent | Keeps the palette disciplined and meaningful |
| SVG radar with a real circular clip path | User correction | Diagnostic primitive | Fixes the broken visual physically rather than masking overflow with CSS |
| Slow background atmosphere; fast control feedback | Refero motion guide | Motion hierarchy | Expressive marketing motion stays separate from frequent interaction feedback |
| Real KZMS, ENDOkey, POVKH LAB and Giulia media | Existing case assets | Evidence | Prevents a text-only or fake-graphic collapse |
| Reduced-motion mode | Refero craft requirements | Accessibility | Removes looping and large movement while preserving state feedback |

## Visual QA target

- Desktop: 1440 × 1000.
- Mobile: 390 × 844.
- Required states: hero loaded, menu open/closed, radar visible, case interactions, result route and final brief.
- No unresolved P0/P1/P2 issues before review.
